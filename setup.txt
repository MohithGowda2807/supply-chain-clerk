5. Pydantic Schema — 45 minutes
Create backend/app/models/intake_record.py — this is the most important schema in the project:
pythonfrom pydantic import BaseModel, field_validator
from datetime import date
from typing import Optional
from statistics import mean

class FieldWithConfidence(BaseModel):
    value: Optional[str | int | date]
    confidence: float  # 0.0 to 1.0

class IntakeRecord(BaseModel):
    batch_no: FieldWithConfidence
    expiry_date: FieldWithConfidence
    quantity: FieldWithConfidence
    supplier_name: FieldWithConfidence
    product_name: FieldWithConfidence
    unit_of_measure: FieldWithConfidence

    @property
    def overall_confidence(self) -> float:
        scores = [f.confidence for f in [
            self.batch_no, self.expiry_date,
            self.quantity, self.supplier_name,
            self.product_name
        ]]
        return mean(scores)

    @property
    def needs_review(self) -> bool:
        return self.overall_confidence < 0.75

6. Extraction Prompt Engineering — 2 hours (most important task)
Create backend/app/prompts/v1_extraction.txt:
You are a pharmaceutical warehouse document parser.

Your task: Extract structured data from the document image provided.

CRITICAL RULES:
1. Return ONLY valid JSON. No explanation, no markdown, no prose.
2. If a field is illegible, unclear, or absent — return null for value and 0.0 for confidence. NEVER invent or guess a value.
3. Confidence score: 1.0 = certain, 0.75 = probable, 0.5 = uncertain, 0.0 = illegible/absent.

Return this exact JSON structure:
{
  "batch_no": {"value": string | null, "confidence": float},
  "expiry_date": {"value": "YYYY-MM-DD" | null, "confidence": float},
  "quantity": {"value": integer | null, "confidence": float},
  "supplier_name": {"value": string | null, "confidence": float},
  "product_name": {"value": string | null, "confidence": float},
  "unit_of_measure": {"value": string | null, "confidence": float}
}

Example for a partially legible handwritten slip:

7. VLM Service Client — 1.5 hours
Create backend/app/services/vlm_client.py:
pythonimport base64, json, re
from pathlib import Path
import google.generativeai as genai
from PIL import Image
import io, os

genai.configure(api_key=os.getenv("GEMINI_API_KEY"))

PROMPT = Path("app/prompts/v1_extraction.txt").read_text()

def preprocess_image(image_bytes: bytes) -> bytes:
    img = Image.open(io.BytesIO(image_bytes)).convert("RGB")
    img.save(buf := io.BytesIO(), format="JPEG", quality=95)
    return buf.getvalue()

async def extract_from_document(image_bytes: bytes) -> dict:
    processed = preprocess_image(image_bytes)
    model = genai.GenerativeModel("gemini-1.5-flash")
    
    response = model.generate_content([
        PROMPT,
        {"mime_type": "image/jpeg",
         "data": base64.b64encode(processed).decode()}
    ])
    
    # Strip markdown if model wraps in ```json
    text = response.text.strip()
    text = re.sub(r'^```json|```$', '', text, flags=re.MULTILINE).strip()
    
    return json.loads(text)
